AKASH AI JARVIS — INTERNAL V10

Base: Internal V9

V10 updates:
- Permanent local identity: AI = Jarvis, user = AK.
- Main chat and Gemini chat use saved Personal Memory as context.
- Basic identity questions can be answered locally without Gemini.
- Saved files are shown as square/card boxes in the Files Vault.

- Existing inline SVG icon system from the V9 base is preserved.
- No API key is included in this ZIP.
- Gemini API key is stored locally in the browser when entered in Settings.

Important:
- Browser-only file storage is local to the browser/device.
- Real Android-wide notifications/background location require the native Android bridge.
- The cyber interface is visual simulation only and performs no real network access, scanning, exploitation, or hacking.
