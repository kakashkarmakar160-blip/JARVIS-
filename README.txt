- Command responses appear in the cyan/blue response area.

- The cyber interface is explicitly simulation-only: no real scanning, network access, exploitation or hacking is performed.
- Chat, calendar, files, settings, Gemini option, notifications and the existing JARVIS dashboard remain included.
