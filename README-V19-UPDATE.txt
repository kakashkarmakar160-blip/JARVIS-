Changes:

- Cyber Simulation opens edge-to-edge across the phone screen.

Install:
1. Extract the ZIP.
2. Publish the extracted project files to the same GitHub Pages repository, including core-video.mp4 and the existing images/assets.
3. Open the HTTPS site and refresh. Opening index.html directly as content:// may restrict browser features.

Video note: autoplay is muted for mobile browser compatibility. Users can tap the page if autoplay is blocked.
