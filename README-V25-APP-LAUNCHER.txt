JARVIS V25 — APP LINK + ICON LAUNCHER UPDATE

What changed:
- The fixed bottom Apps button opens a dedicated app launcher screen after the startup camera scan/password gate is passed.
- The launcher displays apps saved in Settings, including the uploaded icon image and app name. Tapping an app icon opens its saved HTTP/HTTPS link in a new tab.
- Settings now includes APP LINK & ICON: enter an app name, enter its link, upload an image file as its icon, and save it. Saved apps can be deleted.
- App names, links, and icons are stored locally in this browser using localStorage. They remain on this device/browser and are not automatically synced to another phone or browser.
- The center A button returns to the main JARVIS dashboard and closes an open overlay/profile screen. The left Apps and right Back buttons remain available after the startup gate; Back closes the current app launcher or modal.
- The bottom dock is hidden while the initial camera/password gate is on screen.

Notes:
- The uploaded icon is limited to 2 MB to help prevent browser storage quota errors.
- Only valid http:// and https:// links are accepted.
- Browser popup protection may ask you to allow opening a new tab.
- Existing inline SVG icon assets and the rest of the V24 project files were retained.
